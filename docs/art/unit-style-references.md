# Unit style references

Research date: 2026-10-13. The user wants visual inspiration before choosing another sprite direction. These are references, not imported game assets.

| Reference | Direction | What to examine |
| --- | --- | --- |
| [Cute & Chibi: Medieval — huberthart](https://huberthart.itch.io/2d-character-cute-chibi-medieval) | Smooth cartoon 2D chibi; SVG sources and sprite sheets | Eight-direction characters, consistent outlines, readable equipment; idle/walk/attack/death animations. The listed character classes are not an exact match for our full roster. |
| [Kingdom Rush — Ironhide](https://www.kingdomrush.com/kingdom-rush) | Cartoon medieval game reference | Compact silhouettes, helmets and weapon proportions, clear color blocks, restrained detail at battlefield size. This is a game art reference rather than a sprite pack. |
| [Tiny Swords — Pixel Frog](https://pixelfrog-assets.itch.io/tiny-swords) | Chibi pixel art for 2D RTS | Warrior, lancer and archer readability, animation timing, faction colors, matching terrain and effects. |
| [MiniFolks — Humans, LYASeeK](https://lyaseek.itch.io/minifhumans) | Small 32×32 pixel characters | Equipment silhouettes and compact animation. Includes versions with and without outlines. |

For the user's current smooth chibi preference, start by comparing huberthart's character designs with Kingdom Rush's battlefield readability. The other two are pixel-art alternatives for comparison. Keep the project fully 2D whichever art direction is chosen.
