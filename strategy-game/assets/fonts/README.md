# Game typography

- Alegreya (variable roman), heading weight 600: titles and menu headings.
- Alegreya Sans Medium: HUD, buttons, body copy and tooltips.

Unmodified font files downloaded from the official Google Fonts repository on 2026-10-13:
https://github.com/google/fonts/tree/main/ofl/alegreya
https://github.com/google/fonts/tree/main/ofl/alegreyasans

Both families ship with their accompanying SIL Open Font License in this folder. The fonts are bundled locally; gameplay does not need a network connection or system font installation.
